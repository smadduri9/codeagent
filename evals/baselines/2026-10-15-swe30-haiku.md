# SWE-bench Lite, 30-task subset, Claude Haiku 5.5 (2026-10-15)

## Setup

- **Tasks:** `evals/slices/swe30.txt`. These are 30 SWE-bench Lite test instances in three tiers of ten, easy, medium and hard, sorted by the size of the reference patch. They come from repositories whose tests run under pytest without Docker: sympy, pytest, sphinx, pylint and flask. Selection rules and seed are in `evals/select_swe30.py`.
- **Validity:** each task was checked locally before any model call. Its environment builds, its failing tests fail before the reference fix (pytest exit 1) and pass after it (exit 0). 30 of 30 passed this check. One original pick was replaced because its test already passed without the fix (`evals/swebench_env.py`).
- **Agent:** codeagent's loop with `claude-haiku-5-5` and thinking disabled. The agent gets at most 20 model calls and 2,000 output tokens per call. Its tools are read, list, glob, grep, write and edit, plus `run_command` limited to `python` and `pytest`. Other approval requests are denied.
- **Grading:** the agent never sees the test patch. After the run, its edits to patched test files are reverted, the test patch is applied, and the task's failing tests run in its own environment. A task counts as solved when they pass (exit 0).
- **Spend:** capped in code (`evals/spend.py`). Before each call, the worst case is checked against a ledger.

## What this shows

- **Run-to-run noise is large at n = 30.** Two runs with identical settings both solved 12, but 6 of 30 task outcomes flipped between them. A single run cannot separate harness changes smaller than this.
- **Compaction, once fixed, did not cost solves.** In this sample it made no measurable difference either way. The 6 tasks where it fired are too few to say more.
- **Cost is not the limit at this scale.** All three 30-task runs together cost $0.75.

## Bugs found by these runs

The first attempts are not in the table because they measured bugs, not the agent:

1. **Unattended approvals denied all `python` and `pytest` commands** (fixed in #74). In the first 3-task pilot, the agent could not reproduce bugs or run tests.
2. **Ripgrep was missing**, so `grep` and `glob` failed. It is a documented requirement and is now installed.
3. **Compaction kept a tool result without its call and dropped the goal** (fixed in #76). With the threshold forced to 8K, the first run solved 9/30. One task ended with an API 400 (`unexpected tool_use_id found in tool_result blocks`). On the tasks where compaction fired, it solved 1, against 3 for each baseline run.

## Limits

- **One model, one subset of 30 tasks, at most three runs per setting.** The confidence intervals are wide.
- **Local environments, not the official SWE-bench Docker images.** Pass rates are not comparable to published leaderboard numbers.
- **Thinking disabled and 20 calls at most.** Both choices limit the agent; they were made to keep the loop simple and the spend predictable.
- **Total live spend for every run here, pilots included: $1.01.**
