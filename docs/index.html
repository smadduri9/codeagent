CodeAgent

A local, CLI-based autonomous coding agent. The model reasons; deterministic software searches, executes, constrains, verifies, persists, and observes.

Capabilities

End-to-end agent mechanics with explicit safety boundaries and verifiable completion.

Tool-calling loop

Native provider tool calls with iteration, repeat, and budget guards.

Permission engine

Table-driven allow, ask, and deny before execution; single-use approvals.

Isolation

Git worktree by default, checkpoints, rollback, and optional Docker sandbox.

Verification

Checks pipeline and completion gate; no verified finish without evidence.

Durable runs

SQLite state, resume after interrupt or quota wait, full event trace.

Engineering

  • Safety decisions are deterministic, not delegated to the model (DESIGN D4).
  • Tool and file output is untrusted and cannot change permission rules.
  • Stable system prompt and tool definitions per run; compaction appends history (D9).
  • Main and cheap model routing for internal vs editing calls (D12).
  • Groq free-tier pacing: rate limits, quota headers, WAITING_QUOTA with resume.

Python 3.12, strict mypy, Ruff, pytest on Ubuntu and macOS. 589 offline pytest cases in CI (live excluded), including a dedicated security suite.

Evaluation

Live results on a 30-task SWE-bench Lite subset, graded by hidden failing tests. Scripted replay guards the loop in CI.

About $0.02 per solved task. Identical runs flipped 6 of 30 outcomes.

17 / 30 Claude Sonnet 5.5, one run

Not significantly above Haiku at n = 30 (McNemar p = 0.13–0.34), at 12 times the cost per solve.

42 / 42 Scripted replay (CI)

A plumbing regression gate through the real loop, tools, and permissions via FakeProvider. Not a capability measure.

Local environments, not the official SWE-bench images, so the numbers are not comparable to leaderboard results. Full report: SWE-bench subset results.
