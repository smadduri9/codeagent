CodeAgent

A local, CLI-based autonomous coding agent. The model reasons; deterministic software searches, executes, constrains, verifies, persists, and observes.

View on GitHub Watch demo Operator guide

Capabilities

Tool-calling loop

Native provider tool calls with iteration, repeat, and budget guards.

Permission engine

Table-driven allow, ask, and deny before execution; single-use approvals.

Isolation

Git worktree by default, checkpoints, rollback, and optional Docker sandbox.

Verification

Checks pipeline and completion gate; no verified finish without evidence.

Durable runs

SQLite state, resume after interrupt or quota wait, full event trace.

Evaluation

40-task suite with scripted replay in CI and quota-aware live slices.

Engineering

  • Safety decisions are deterministic, not delegated to the model (DESIGN D4).
  • Tool and file output is untrusted and cannot change permission rules.
  • Stable system prompt and tool definitions per run; compaction appends history (D9).
  • Main and cheap model routing for internal vs editing calls (D12).
  • Groq free-tier pacing: rate limits, quota headers, WAITING_QUOTA with resume.

Python 3.12, strict mypy, Ruff, pytest on Ubuntu and macOS. 442 offline pytest cases in CI (live excluded), including a dedicated security suite.

Scope

Built through phase 8 (initial release). Tuned for small repositories and Groq free-tier context and quota limits. Agentic search with grep, glob, and read_file; no code index until evaluation data justifies it.
